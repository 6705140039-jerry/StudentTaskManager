Project Charter

1. Project Information

Project Name: Student Task Manager

Project Type: C# Console Application

Project Purpose:
The Student Task Manager is a simple application designed to help students organize and manage their academic tasks.

⸻

2. Project Background

Students often have multiple assignments, activities, and deadlines to manage. Without a simple task management system, it can be difficult to keep track of unfinished work.

This project will create a basic task management application that allows students to add, view, complete, and delete tasks.

⸻

3. Project Objectives

The main objectives are:

1. Create a simple and easy-to-use task management application.
2. Allow users to add new tasks.
3. Allow users to view their tasks.
4. Allow users to mark tasks as completed.
5. Allow users to delete tasks.
6. Apply Object-Oriented Programming concepts in C#.
7. Create project documentation using Markdown.

⸻

4. Project Scope

In Scope

The application will provide:

* Student information
* Task creation
* Task descriptions
* Task due dates
* Task status
* Task viewing
* Task completion
* Task deletion
* Console-based user interaction

Out of Scope

The first version will not include:

* User authentication
* Online synchronization
* Mobile application
* Email notifications
* Advanced user permissions
* Cloud database

⸻

8. Project Risks

Risk	Impact	Solution
Programming errors	Medium	Test the application regularly
Incorrect user input	Medium	Validate user input
Data is not permanently stored	Medium	Add database support in a future version
Missing requirements	High	Review project requirements before submission

⸻

9. Success Criteria

The project will be considered successful when:

* The application runs without major errors.
* Users can add tasks.
* Users can view tasks.
* Users can complete tasks.
* Users can delete tasks.
* The code uses appropriate OOP concepts.
* All required documentation is included.
* The project is uploaded to GitHub.
